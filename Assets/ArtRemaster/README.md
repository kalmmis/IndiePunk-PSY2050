# PSY2050 아트 리마스터

`source/`는 built-in image_gen으로 생성한 고해상도 신규 원화와 스프라이트 아틀라스입니다. `portraits/`, `sprites/`, `backgrounds/`, `ui/`는 게임이 실제 사용하는 리소스입니다. `manifest.json`은 웹 빌드 키와 파일을 연결합니다.

세 캐릭터의 정체성, 원작자 이름, 시나리오와 게임 규칙을 보존했습니다. 기존 작업 파일은 그대로 두고 새 에셋을 이 폴더에서 관리합니다. 웹 빌드는 이 폴더를 우선 사용합니다.

캐릭터·배경·드론·이펙트는 신규 AI 이미지 원화이며, UI 프레임·로고·크레딧은 읽기 쉬운 코드 기반 벡터 그래픽으로 제작합니다. 정확한 생성 프롬프트는 `prompts.json`에 보존합니다.

스프라이트 아틀라스는 자동으로 프레임을 분리하고 동일한 캔버스에 정렬합니다. 이미지 색을 바꾸는 연출은 비활성 초상화 등 게임 상태 표현에만 사용합니다.

미리보기는 [gallery.html](gallery.html), 적용 화면은 [preview.jpg](preview.jpg), 실제 연결 목록은 [manifest.json](manifest.json)에서 볼 수 있습니다. 웹 빌드의 기존 이미지 32개를 모두 새 아트로 교체했으며 게임용 이미지 42종, 보조 스프라이트 6종을 제공합니다. 원래 Unity 씬의 참조는 보존되어 있습니다.
