PSY2050 — PlayStation / PS1 네이티브 포트

실행
1. 압축파일을 모두 풀어 주세요.
2. PS1 에뮬레이터에서 PSY2050.cue를 열어 주세요.
3. PSY2050.bin과 PSY2050.cue는 반드시 같은 폴더에 두세요.
   CUE 파일을 통해 데이터 트랙과 원본 음악 트랙을 함께 불러옵니다.
   파일 이름을 바꾸려면 CUE 안의 BIN 파일 이름도 같이 수정해야 합니다.

PCSX ReARMed의 MIPS 인터프리터 / HLE BIOS 환경에서 실행을 검증했습니다.
DuckStation 등 실제 BIOS를 사용하는 에뮬레이터는 사용 중인 BIOS 설정이 필요합니다.
이 배포본에는 에뮬레이터나 PS1 BIOS를 동봉하지 않습니다.
PSY2050.EXE는 디스크 없이 텍스처·대사·효과음을 실행할 수 있는 보조 실행 파일입니다.
원본 BGM까지 재생하려면 CUE로 실행하세요.

조작 (PS1 패드 기준, 키보드 대응은 에뮬레이터에서 설정)
  방향키        이동 / 타이틀에서 시작 챕터 선택
  × / ○ / R1    발사. 계속 누르면 5초마다 강화되며 적과 탄막이 최대 70% 속도로 느려집니다.
  □             저속 정밀 이동. 타이틀에서는 무적 연습 모드 HELP ON/OFF
  Start         게임 시작 / 일시정지 / 재개
  × / ○ / Start 다음 대사
  Select        현재 대화 건너뛰기. 스토리 분기 이벤트는 적용됩니다.
  Select+Start  타이틀로 돌아가기
  × / ○         사망 후 잠시 기다렸다가 부활 (약 3초간 보호)

수록 내용
  원본 챕터 1~4, 에필로그, 한글 대사 286페이지, 적 출현 데이터 258개,
  미나·레이나·시간의 소녀 리마스터 그림, 3단계 보스와 스토리 분기,
  원본 72초 BGM 전체 CD 오디오 트랙과 SPU 발사/피격 효과음입니다.

PS1 사양에 맞춘 조정
  320x240 / NTSC 화면과 세로형 플레이필드, 256색 캐릭터 텍스처,
  15비트 배경, 고정 소수점 게임 로직, 목표 60fps로 구성했습니다.
  적 32개 / 아군탄 24개 / 적탄 256개를 지원합니다.
  원작 대비 이동·충돌·회전 계산, UI·일부 연출 및 효과음은 간소화했습니다.
  메모리카드 자동 저장은 없으며 타이틀의 챕터 선택이나 에뮬레이터의
  세이브 스테이트를 사용할 수 있습니다.

검증 범위
  디스크 부팅, 패드, 대화 대기/진행/스킵, 시간 감속, 보스 3단계,
  피격·부활, 처치/시간초과 분기, 모든 챕터와 에필로그·엔딩 연결,
  원본 BGM 반복과 SPU 효과음을 검증했습니다.
  챕터 연결 검사는 에뮬레이터 RAM에서 대기시간과 보스 결과를 조정했습니다.
  실제 PS1 기기와 DuckStation에서는 아직 검증하지 않았습니다.
