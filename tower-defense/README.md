# PSY2050 · LAST SIGNAL

원작 PSY2050의 **별도 시간선**을 다루는 독립 타워디펜스입니다. 실험도시, 리안 병원, 미사의 기억, 미나의 공간 능력과 레이나의 불꽃을 이어받아, 피난민의 마지막 구조 신호를 지키는 방어전으로 만들었습니다. 기존 Unity·슈팅·FPS 프로젝트를 실행하거나 빌드할 필요가 없습니다.

## 바로 플레이

**`build/tower-defense/index.html`을 브라우저로 여세요.** 이미지·글꼴·음악·게임 코드를 모두 내장한 약 4.3MB HTML 한 파일입니다. 다른 컴퓨터에 이 파일만 복사해도 오프라인으로 플레이할 수 있습니다. HTML 소스 편집기로 열리는 경우 Chrome·Edge·Safari에서 파일을 여세요.

로컬 서버를 사용할 수도 있습니다.

```sh
npm run serve --prefix tower-defense
# http://localhost:8082
```

작전 시작 → 브리핑 → 거점 배치 시작 → 캐릭터 선택 → 빛나는 네모 거점 클릭 → 웨이브 시작 순서입니다. 처음에는 **미나 + 리타 + 시간의 소녀**를 굽은 길 주변에 배치하는 조합을 권합니다.

## 친구에게 보내기

`build/tower-defense/PSY2050-LAST-SIGNAL.zip`을 보내세요. 친구는 압축을 모두 풀고 **`PSY2050-LAST-SIGNAL/START.html`**을 브라우저로 열면 됩니다. 게임 전체를 내장한 HTML과 한국어 안내문만 포함하며, 설치나 인터넷 연결은 필요 없습니다.

게임을 다시 빌드한 뒤 ZIP을 갱신하려면 다음 명령을 실행하세요.

```sh
npm run package --prefix tower-defense
```

## 방어 규칙

- 적은 표시된 도로를 따라 한 방향으로 이동합니다. 길을 바꾸거나 막을 수 없습니다.
- 캐릭터의 **아니마 잔상**을 정해진 거점에 고정합니다. 배치 뒤 이동하지 않으며, 같은 인물의 잔상을 여러 곳에 놓을 수 있습니다.
- 적 처치와 웨이브 완료로 에테르를 얻습니다. 배치한 잔상을 선택하면 Lv.3까지 강화하거나 투자 비용의 70%를 받고 회수할 수 있습니다.
- 일반 적이 신호탑에 닿으면 내구도가 1–3 감소합니다. 시작 내구도는 20이며 **보스가 통과하면 즉시 패배**합니다.
- 구역마다 6개 웨이브, 마지막에 보스 1명. 마지막 보스를 포함해 모든 적을 처치하거나 일반 적이 통과해 전장이 비면 다음 웨이브로 넘어갑니다.
- 구역을 완료하면 다음 구역을 해금합니다. 내구도 20은 별 3개, 12 이상은 별 2개, 그 미만은 별 1개입니다. 최고 별 기록을 저장합니다.
- 새 구역에서는 배치와 에테르를 초기화합니다. 구역 1/2/3의 초기 에테르는 440/550/680입니다.
- 자동 웨이브는 완료 후 게임 시간 3.5초를 기다립니다. 새 구역에서는 자동 시작이 꺼집니다. 배속은 1×/2×/3×입니다.

## 캐릭터 6종

| 인물 | 방식 | 역할 |
| --- | --- | --- |
| 미나 | 공간 광탄 속사 | 저렴하고 빠른 단일 공격. Lv.3에서 3연발 시각 효과와 위력 강화 |
| 리타 | 전기 신호 연쇄 | 최대 3/4/5기의 가까운 적을 이어서 공격 |
| 시간의 소녀 | 원형 시간장 | 사거리 안 모든 적을 45/53/61% 감속. 보스에게도 적용 |
| 하은 · 신규 | 음향 공명 폭발 | 착탄 주변 범위 공격. 강화 시 피해와 폭발 범위 증가 |
| 율 · 신규 | 공간창 직선 관통 | 긴 사거리, 경로상 적을 동시 타격하며 장갑 무시 |
| 세린 · 신규 | 기억 공명 지원 | 주변 아군 피해 +25/35/45%, 웨이브마다 에테르 +14/20/26. 공격 증폭은 가장 강한 것만 적용 |

미나·시간의 소녀·레이나는 기존 초상화와 스프라이트를 재사용합니다. 리타의 전기 신호 거점, 새 아군과 보스는 이 외전용 각색입니다. 추가 초상화는 로컬 SVG 벡터 일러스트이며, 전장 캐릭터는 Canvas로 그립니다.

## 3개 스테이지와 보스

| 구역 | 장소 | 보스 | 전투 패턴 |
| --- | --- | --- | --- |
| 1. 재가 내리는 거리 | 리안 병원 동쪽 대피로 | **레이나** · 불꽃의 아니마 | 6초마다 가까운 거점 2곳을 2.1초 봉인. 체력 절반 이하에서는 화염 장벽으로 일부 피해 감소 |
| 2. 침묵한 중계국 | 제7 통신구 | **베스퍼** · 침묵의 전도체 | 7초마다 적 전체에 방어막. 근처 아군 공격 속도 저하 |
| 3. 기억의 새벽 | 도시 중심 기억 보관소 | **오르페** · 기억을 삼키는 자 | 8초마다 분열 잔상 소환. 체력 절반 이하에서 소환 수 2→4, 이동 속도 증가 |

**베스퍼**는 레이나에게 리안 병원의 감시망을 열어 준 전기 해커입니다. 감시를 끝내려 모든 통신을 차단해, 구조 신호까지 끊었습니다. **오르페**는 레이나에게 실험의 기억을 보여 준 기록 보관자입니다. 동료들의 고통을 없앤다는 명분으로 도시의 기억과 인격을 하나로 통합하려 합니다. 세 사람은 같은 진실을 알게 되었지만 서로 다른 수단으로 도시에 저항합니다. 브리핑·보스 통신·구역별 후일담·최종 엔딩과 인물 기록에서 관계를 확인할 수 있습니다.

원작의 이름 없는 시간 능력자는 '시간의 소녀'로 표기했습니다. 새 캠페인은 원작 정식 후속편이 아닌 별도 외전 설정입니다. 구체적인 출처와 각색 구분은 [시나리오 문서](SCENARIO.md)를 참고하세요.

## 조작과 저장

| 입력 | 동작 |
| --- | --- |
| 마우스 / 터치 | 캐릭터 선택, 거점 배치, 배치된 잔상 선택 |
| 1–6 | 캐릭터 선택 |
| Space | 웨이브 시작 |
| U | 선택한 잔상 강화 |
| Q | 시간 균열: 4초간 적 전체 76% 감속, 재사용 32초 |
| P | 일시정지 |
| Esc | 선택 해제 / 일시정지 / 대화창 닫기 |
| M | 음악·효과음 켜기 / 끄기 |
| 지도에서 방향키 → Enter | 배치 거점 순회 → 배치 또는 선택 |

배치와 업그레이드, 웨이브 완료 시 자동 저장합니다. 전투 중의 임시 배치와 수입은 다음 웨이브 준비 때 확정됩니다. **이어하기는 가장 최근 웨이브가 시작되기 직전으로 복원**하므로, 브라우저를 닫아도 같은 웨이브에 재도전할 수 있습니다. `psy2050-td-*` 저장 키를 사용해 기존 게임의 진행과 분리합니다. 같은 파일 위치·같은 브라우저 또는 같은 서버 주소에서 이어갈 수 있습니다. 브라우저가 저장소를 차단한 경우 현재 플레이는 가능하지만 진행 보존은 제한됩니다.

음악은 기본 음소거입니다. 상단 음표 또는 M으로 켜면 원작 BGM과 합성 효과음이 재생됩니다. 창이 가려지거나 다른 탭으로 이동하면 전투를 일시정지합니다.

## 빌드와 검증

Node.js 20 이상으로 실행합니다. npm 패키지 설치 없이 빌드·엔진 테스트가 가능합니다. 최적화된 원본 아트가 `assets/`에 포함되어 있습니다.

```sh
npm run build --prefix tower-defense
npm test --prefix tower-defense
```

13개 엔진 테스트는 경로 연결, 웨이브 구성, 고정 배치, 구매·강화·환급, 장갑·방어막, 공격 패턴, 지원 증폭·수입, 감속·쿨다운, 보스별 능력·각성, 패배 동작을 검사합니다. 정상 수입만 쓰는 자동 플레이로 **3개 구역과 18개 웨이브를 모두 완주**하며 전투 도중 캐릭터의 위치가 변하지 않는지도 확인합니다.

선택적인 `npm run test:browser --prefix tower-defense`는 Playwright Core와 Chrome이 설치된 환경용입니다. `PSY_PLAYWRIGHT_MODULE`·`CHROME_PATH`로 설치 경로를 지정할 수 있습니다. 오프라인 파일 실행, 실제 클릭·키보드, 업그레이드·회수, 저장 복원, 일시정지, 모바일 레이아웃과 외부 요청 여부를 검사합니다.

원본 아트를 변경한 뒤 리소스를 다시 최적화하려면 Python + Pillow로 `python3 tower-defense/tools/prepare-assets.py`를 실행한 다음 빌드하세요. 추가 인물 SVG는 빌드 스크립트에서 재생성합니다.

```text
tower-defense/src/data.js       캐릭터·구역·보스·웨이브·시나리오
tower-defense/src/engine.js     전투·배치·강화·경로·경제·보스 규칙
tower-defense/src/renderer.js   전술 지도·캐릭터·이펙트 Canvas 렌더러
tower-defense/src/app.js        입력·화면·음향·자동 저장·진행
tower-defense/assets/           최적화된 원본 아트·음악·신규 SVG
tower-defense/tools/            빌드·선택적 원본 변환·테스트
build/tower-defense/index.html  단독 오프라인 실행 파일
```
