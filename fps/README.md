# PSY2050 · ANIMA / FPS

PSY2050의 미나, 레이나, 마법·텔레포트·시간 감속 설정을 **1인칭 3D 마법 전투**로 재구성한 별도 WebAssembly 프로젝트입니다. 원본 Unity 프로젝트와 기존 `web/` 포트는 독립적으로 유지합니다.

## 실행

친구에게 보낼 로컬 실행판은 `build/fps/PSY2050-FPS-local.zip`입니다. 압축을 전부 풀고 `index.html`을 열면 됩니다. 운영체제별 바로 열기 파일, 한국어 안내와 레이나 GLB를 함께 포함합니다. 받는 사람은 개발 도구를 설치할 필요가 없습니다. Python 3가 있는 환경에서는 동봉한 `serve.py`로 로컬 서버도 선택적으로 실행할 수 있습니다.

`build/fps/index.html`을 데스크톱 브라우저에서 엽니다. WASM, 초상화, 글꼴, 음향과 3D 메시 생성 코드를 HTML에 포함하므로 게임은 오프라인에서도 실행됩니다. WebGL 2와 키보드·마우스가 필요합니다.

```sh
npm run serve --prefix fps
```

`http://localhost:8081` → **작전 시작** → **전장 진입**. 마우스 고정을 지원하지 않으면 창 모드 조준으로 자동 전환합니다. 창 모드에서도 마우스로 시점을 돌리고 화면 가장자리에 커서를 두면 계속 회전합니다. 커서가 게임 밖으로 나가면 일시정지합니다.

## 조작

| 조작 | 동작 |
| --- | --- |
| 마우스 | 시점 / 조준 |
| WASD / 방향키 | 이동 |
| 왼쪽 클릭 유지 | 손과 마법진에서 사이킥 광탄 연속 시전 |
| 오른쪽 클릭 유지 → 놓기 | 공명탄 충전 → 시전, 충전 중 정밀 조준 |
| E 유지 → 빈 지면 조준 → 놓기 | 지정한 위치로 순간이동 |
| R 유지 | 명상으로 마력 빠르게 회복, 시전 중단 |
| Q 유지 | 시간 감속: 적·적 탄막 속도 28%, 미나의 이동·마법 속도 유지 |
| Shift / Space | 달리기 / 점프 |
| Esc / P | 일시정지, P로 재개 |
| M | 음소거 전환 |

미나의 자유 이동은 **텔레포트 능력**입니다. E를 누르면 조준한 지면에 도착 마법진이 나타나며, 놓는 순간 이동합니다. 경로의 엄폐물을 통과할 수 있고, 도착 지점이 비어 있어야 합니다. 최대 사거리 55m, 재사용 대기 0.75초이며 마력과 시간 에너지를 소모하지 않습니다. 잘못된 지점은 붉은 표시와 안내로 알려 줍니다.

마력은 최대 100입니다. 광탄은 4, 공명탄은 18을 소모합니다. 공명탄은 0.18초 이상 충전해야 시전되고 약 1.18초에 완전히 충전됩니다. 마력은 자연 회복하며 R을 유지하면 더 빠르게 회복합니다. 광탄과 공명탄은 실제로 날아가는 마법 투사체이며 엄폐물에 막힙니다. 총기·탄창·재장전은 사용하지 않습니다.

시간 에너지는 Q 사용 중 소모되고 해제하면 회복합니다. 소진하면 Q를 놓고 20% 이상 회복해야 다시 사용할 수 있습니다. 방어막은 피해 없이 5초 뒤부터 회복하고, 청록색 회복 아이템은 체력·마력·시간 에너지를 회복합니다.

## 레이나 3D 모델

`Assets/ArtRemaster/portraits/portrait_fire.png`를 기준으로 긴 갈색 머리, 호박색 눈, 붉은 금장 드레스, 흰 소매, 남색 크라바트를 입체 메시로 모델링했습니다. 얼굴·머리카락·의상·손가락에 실제 깊이가 있는 스타일화된 모델이며, 전투에서 머리·머리카락·시전 팔·치마·다리가 움직입니다. 일러스트에 보이지 않는 하체와 신발은 기존 색에 맞춰 보완했습니다.

타이틀의 **레이나 모델** 또는 `http://localhost:8081/?model=reina`에서 원본 일러스트와 나란히 확인할 수 있습니다. 드래그로 회전, 스크롤로 확대하고 정면·측면·후면 버튼을 사용할 수 있습니다.

같은 모델을 `build/fps/reina-model.glb`로 내보냅니다. 36,815개 삼각형과 9개 스킨 조인트를 포함한 glTF 2.0 바이너리이며, 외부 텍스처가 필요 없습니다. 다운로드 버튼을 제공하려면 이 GLB도 HTML 옆에 배포합니다. 게임과 모델 뷰어 자체는 HTML 하나로 실행됩니다. GLB는 바인드 포즈의 모델을 제공하며 전투 애니메이션은 렌더러에서 적용합니다.

## 플레이 구성

1. **네온의 잔향** — 옥상 드론 포위망 돌파
2. **멈춰 버린 시간** — 시간 중계기, 강화 드론과 교전
3. **아니마의 불꽃** — 반응로, 레이나의 3단계 화염 공격

3개 구역, 9개 웨이브, 적 49기를 돌파하면 엔딩이 표시됩니다. 드론의 외형과 전투 규칙을 유지하면서 보스는 레이나의 인간형 모델로 교체했습니다. 구역 진입 시 이어하기를 저장하며 감도·시야각·음량·비 설정도 저장합니다. 세이브 키는 `psy2050-fps-*`입니다. 같은 로컬 서버 주소에서 이어하기를 이용할 수 있습니다.

이 캠페인은 FPS에 맞춰 새로 구성했습니다. 원작의 세로형 이동, CSV 웨이브와 전체 분기 대사를 사용하는 포트는 `web/` 및 `build/wasm/`에 있습니다.

## 독립 빌드

Node.js 20 이상과 npm 10 이상이 필요합니다. Unity나 기존 `web/node_modules`에 의존하지 않습니다.

```sh
npm ci --prefix fps
npm run build --prefix fps
npm test --prefix fps
```

배포 ZIP을 다시 만들려면 개발 PC에서 `npm run package --prefix fps`를 실행합니다. 패키징에만 Python 3를 사용하며 게임 실행에는 필요하지 않습니다.

게임 시뮬레이션은 AssemblyScript로 실제 WASM 바이너리로 컴파일합니다. 렌더러는 외부 라이브러리 없는 WebGL 2 인스턴싱과 스킨 메시 셰이더를 사용합니다. 게임 실행에 CDN이나 네트워크 연결이 필요 없습니다.

```text
fps/src/engine.ts             WASM: 이동·마법·텔레포트·AI·충돌·피해·시간·웨이브
fps/src/worlds.json           3개 구역의 지형·스폰·브리핑
fps/src/world.generated.ts    빌드 시 생성하는 WASM 지형 데이터
fps/src/models.js             레이나·미나의 손 입체 메시와 스킨 조인트
fps/src/renderer.js           카메라·도시·드론·캐릭터·마법·텔레포트 이펙트
fps/src/app.js                입력·마우스 고정·UI·음향·저장
fps/tools/build.mjs           WASM 컴파일·음향 변환·단일 HTML 패키징
fps/tools/export-model.mjs    전투와 같은 메시의 GLB 내보내기
build/fps/index.html          실행용 HTML (약 12 MB)
build/fps/game.wasm           시뮬레이션 바이너리
build/fps/reina-model.glb     레이나 스킨 메시 (약 7 MB)
build/fps/reina-model.json    모델 통계·조인트·기준 일러스트 경로
build/fps/asset-sources.json  리소스 경로·WASM SHA-256
```

## 검증

`npm test --prefix fps`는 실제 WASM으로 이동·중력·충돌, 텔레포트의 미리보기·도착·엄폐물 통과·잘못된 지점, 마법 비행·충돌·충전·마력 회복, 감속, 피격·사망, 웨이브·보스 단계를 확인합니다. 일반 입력만 사용하는 자동 플레이로 3개 구역과 보스를 완주합니다.

앱 입력 검사는 포인터 고정 거절·미지원·무응답과 창 모드 조준, E/우클릭/R 입력 및 일시정지 중 입력 취소를 재현합니다. 모델 검사는 배포 GLB를 읽어 입체 범위·법선·조인트·역바인드 행렬과 전투 메시와의 일치를 확인합니다.

선택적인 Chrome 통합 검증 스크립트는 `fps/tools/browser.test.mjs`입니다. Playwright Core가 설치된 별도 환경에서 실행할 수 있습니다. `CHROME_PATH`, `PSY_PLAYWRIGHT_MODULE`로 경로를 지정합니다. URL의 `?test=1`에서만 조작용 테스트 인터페이스가 노출되며 일반 실행의 `PSY2050_FPS.snapshot()`은 조회 전용입니다.
