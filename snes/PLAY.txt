PSY2050 — SUPER FAMICOM / SNES 데메이크

실행
1. 압축파일을 전부 풀어 주세요.
2. Snes9x에서 PSY2050.sfc를 열어 주세요. 에뮬레이터는 별도입니다.
   공식 배포: https://github.com/snes9xgit/snes9x/releases
3. 같은 폴더의 PSY2050.msu와 PSY2050-1.pcm를 유지하면 원본 BGM이 재생됩니다.
   파일 이름을 바꿀 때에는 세 파일의 PSY2050 부분을 모두 동일하게 바꿔야 합니다.
   MSU-1 미지원 에뮬레이터나 SFC 단독 실행에서도 게임과 효과음은 동작합니다.

아래 버튼은 SNES 패드 기준입니다. 키보드 대응은 에뮬레이터에서 설정해 주세요.

타이틀
  위/아래 : 시작 챕터 선택 (1~4, 에필로그)
  A / Start : 선택한 챕터 시작
  X : HELP 모드 전환 (무적 연습 모드, 기본 꺼짐)

게임
  방향키 : 이동
  A / B / Y : 발사. 계속 누르면 5초마다 강화되고 적과 탄막이 최대 70% 속도로 느려집니다.
  X : 저속 정밀 이동
  Start : 일시정지 / 재개
  Select + Start : 타이틀로 돌아가기

대화
  A / B / Start : 다음 대사
  Select : 현재 대화 건너뛰기 (스토리 분기 이벤트는 적용)

사망
  잠시 기다린 뒤 A / B : 부활. 약 3초간 보호됩니다.

포함 내용과 차이
  원본 스테이지 1~4와 에필로그, 한글 대사 286페이지, 리마스터 캐릭터·배경,
  적 출현 데이터, 시간 감속, 3단계 보스, 처치/시간초과에 따른 스토리 분기를 담았습니다.
  SNES용 C/65816 프로그램으로 새로 작성한 데메이크입니다.
  256x224 화면, 16색 팔레트, 고정 소수점 좌표, 최대 적 12/아군탄 12/적탄 48로 조정했습니다.
  빔은 작은 스프라이트를 이어서 표시하며 회전/부채꼴 이동 및 판정에는 근사값을 사용합니다.
  목표 업데이트 속도는 30fps이고 혼잡한 장면에서는 느려질 수 있습니다.
  원본 UI·일부 애니메이션·오디오 연출은 간소화했습니다. 진행 자동 저장은 없으며
  타이틀에서 챕터를 선택하거나 에뮬레이터의 세이브 스테이트를 사용할 수 있습니다.

검증
  Snes9x 1.63 libretro, 기본 CPU 속도에서 부팅·패드·대화·보스·엔딩·사운드를 검증했습니다.
  챕터 연결 테스트는 대기시간과 보스 결과를 에뮬레이터 RAM에서 조정해 진행했습니다.
  실제 SNES 기기에서는 아직 검증하지 않았습니다.
